# Support

Use the repository's issue form for a problem reproducing a documented command,
test, or aggregate result. Include your operating system, Python and TensorFlow
versions, the command you ran, and a minimal error excerpt.

This public showcase cannot provide course datasets, holdout labels, answer
files, checkpoints, or submission exports. Obtain restricted materials only
from their authorized source.

Do not post credentials, private data, proprietary files, or an unpatched
security vulnerability in a public issue. Follow [SECURITY.md](SECURITY.md) for
sensitive reports.
